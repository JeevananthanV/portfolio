1. Glamours Gatherings — Model Event Platform

Type: Full Stack Web Application

Technology Stack

Frontend: React.js, JavaScript, HTML5, CSS3
Backend: Node.js
Database: SQL
Project Overview

Glamours Gatherings is an online platform designed to organize and manage fashion events, modeling competitions, casting calls, and promotional campaigns. It allows models to register, browse upcoming events, and submit applications while event organizers can manage registrations.

Problem Solved

Traditional model event registrations are mostly handled through social media or manual forms, making it difficult to manage applicants and event details.
